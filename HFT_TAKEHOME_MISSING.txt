STATUS DEFINITIONS:
OFFICIAL PUBLIC TAKE-HOME = source published by employer itself.
OFFICIAL PROCESS / SPEC NOT PUBLIC = employer confirms exercise exists, but
there is no genuine accessible problem statement to reproduce.
CANDIDATE REPORT = one person's recollection/experience; not employer-issued.
CANDIDATE-ATTRIBUTED PROJECT = candidate code in public repo; not original spec.
THIRD-PARTY OA INDEX = company attributed by a public practice provider;
not firm-authenticated and not necessarily a software engineering assessment.
CONSTRUCTED = an invented practice problem; never imply real hiring use.
LIVE INTERVIEW = NOT a take-home and must be labeled as such.
